# Lotus Flower Craft — онлайн дэлгүүр

Гэрийн ургамал, шүүслэг/кактус, зохиомж, улирлын ургамал болон баглаа цэцгийн бүрэн e-commerce сайт: дэлгүүр, сагс, захиалга, Монголын онлайн төлбөр, админ панел. Build хийх шаардлагагүй — HTML, CSS, JavaScript ба нэмэлт сангүй Node.js сервер.

## Боломжууд

**Дэлгүүр**
- Ангилал, хайлт, эрэмбэлэлт, хадгалсан бараа (♥)
- Бараа бүр өөрийн холбоостой (`/?product=<id>`) — Facebook-т хуваалцахад зураг, гарчиг нь гарна
- Үлдэгдэл: «Сүүлийн 3 ширхэг», «Дууссан»
- Хүргүүлэх эсвэл очиж авах, үнэгүй хүргэлтийн босго
- Промо код (хувь эсвэл тогтмол дүн)
- QPay, SocialPay, карт, данс, Storepay, хүргэлтээр төлөх
- Захиалга хянах (дугаар + утас), энэ төхөөрөмжөөс өгсөн захиалгын жагсаалт
- Хүргэлт ба буцаалт, үйлчилгээний нөхцөл, нууцлалын бодлого
- SEO: бараа бүрийн meta/OG tag, `sitemap.xml`, `robots.txt`

**Админ панел** (`/admin.html`)
- Тойм: өнөөдрийн / сарын / нийт орлого, төлөв тус бүрийн захиалга, их зарагдсан, үлдэгдэл бага бараа
- Бараа: нэмэх, засах, устгах, нуух, зураг оруулах (автоматаар багасгана), үнэ, үлдэгдэл, дараалал
- Захиалга: хайх, төлөвөөр шүүх, төлөв солих (цуцлахад үлдэгдэл буцна), дотоод тэмдэглэл, төлбөрийг банкнаас шалгах
- Промо код: хувь/дүн, доод дүн, ашиглах хязгаар, дуусах огноо
- Тохиргоо: дэлгүүрийн мэдээлэл, хүргэлтийн төлбөр, очиж авах хаяг, банкны данс, QPay QR

**Мэдэгдэл** — шинэ захиалга, төлбөр орох бүрт Telegram-аар мэдэгдэнэ.

## Ажиллуулах

```bash
cp .env.example .env   # ADMIN_PASSWORD болон бусад түлхүүрээ оруулна
npm start              # http://localhost:8000, админ: http://localhost:8000/admin.html
```

Node 18+ хангалттай, `npm install` хэрэггүй.

Сервергүйгээр (GitHub Pages, Netlify гэх мэт) байршуулж бас болно: тэгвэл `js/data.js`-ийн бараа харагдаж, зөвхөн гараар баталгаажуулах төлбөр (данс, Storepay, хүргэлтээр) ажиллана. Админ панел, промо код, захиалга хянах нь сервер шаарддаг.

### Байршуулах (production)

1. Node 18+ ажилладаг VPS эсвэл хостинг (жишээ нь Render, Railway, Fly.io, DigitalOcean).
2. `.env`: `PUBLIC_URL=https://таны-домэйн.mn`, `ADMIN_PASSWORD` (урт, давтагдашгүй), төлбөрийн түлхүүрүүд.
3. **https** заавал — QPay callback, Голомтын буцах хаяг, админы cookie үүнд тулгуурлана.
4. `data/` хавтас (бараа, захиалга, тохиргоо, зураг) **байнгын диск** дээр байх ёстой. Түр дисктэй хостингт `DATA_DIR`-ийг байнгын volume руу заана. Энэ хавтсаа тогтмол нөөцлөөрэй.

## Бүтэц

| Файл | Агуулга |
| --- | --- |
| `index.html`, `js/app.js`, `css/styles.css` | Дэлгүүр |
| `admin.html`, `js/admin.js`, `css/admin.css` | Админ панел |
| `js/common.js` | Хамтын туслах (үнэ, зураг/дүрслэл, төлөвийн нэр) |
| `js/data.js` | Ангилал, төлбөрийн хэлбэр, мэдээллийн хуудас, **анхны** бараа ба тохиргоо |
| `server/server.js` | HTTP сервер, нийтийн API, SEO |
| `server/admin.js` | Админ нэвтрэлт ба API |
| `server/orders.js` | Үнийн тооцоо, захиалга, төлөв, хянах |
| `server/store.js` | `data/` доторх JSON хадгалалт, шалгалт |
| `server/notify.js` | Telegram мэдэгдэл |
| `server/payments/qpay.js` | QPay Merchant API v2 |
| `server/payments/golomt.js` | Голомт банкны e-commerce (карт, SocialPay) |

Сервер анх асахдаа `js/data.js`-ийн барааг `data/products.json` руу хуулна. Үүнээс хойш бараа, тохиргоог **админ панелаас** засна (`js/data.js`-ийн `PRODUCTS`, `SHOP` өөрчлөлт нөлөөлөхгүй). Ангилал, мэдээллийн хуудсын текстийг `js/data.js`-д засна.

## Солих шаардлагатай зүйлс

1. **Лого** — `assets/Lotus_flow_craft_logo_new.svg` нь түр лого. Жинхэнэ файлаа яг ижил нэрээр нь хуулна.
2. **Бараа, үнэ, холбоо барих мэдээлэл, данс** — түр утгууд. Админ панелаас засна.
3. **Мэдээллийн хуудас** — `js/data.js` → `PAGES` (хүргэлт, буцаалт, нөхцөл, нууцлал)-ыг өөрийн бодлогоор засна.

## Төлбөрийн хэлбэрүүд

| Хэлбэр | Хэрхэн ажиллах | Шаардлага |
| --- | --- | --- |
| **QPay** | QR нэхэмжлэх үүсгэж, бүх банкны апп-аар уншуулна. Утсан дээр банкны апп руу шууд холбоос гарна. Төлсний дараа QPay callback ирж захиалга «Төлөгдсөн» болно. | QPay-тэй merchant гэрээ → `QPAY_*` |
| **QPay (тогтмол QR)** | Админ тохиргоонд оруулсан QR-ийг харуулж, гүйлгээний утга дээр захиалгын дугаар бичүүлнэ. Гараар баталгаажуулна. | QR зураг |
| **SocialPay** | Голомт банкны gateway → SocialPay апп руу шилжинэ. | Голомттой e-commerce гэрээ → `GOLOMT_*` |
| **Карт** (Visa, Mastercard, UnionPay) | Голомт банкны картын хуудас руу шилжиж, буцаж ирэхэд банкнаас төлөвийг шалгана. | Голомттой e-commerce гэрээ → `GOLOMT_*` |
| **Дансаар шилжүүлэх** | Данс, гүйлгээний утгыг хуулах товчтой харуулна. | Админ → Тохиргоо → данс |
| **Storepay** (хуваан төлөх) | 100,000₮-с дээш захиалгад. Дэлгүүр Storepay-ээр дамжуулан үйлчлүүлэгчийн утас руу нэхэмжлэх илгээнэ (merchant гэрээний дагуу). | Storepay-тэй merchant гэрээ |
| **Хүргэлтээр төлөх** | Бэлнээр эсвэл картаар. | — |

Түлхүүр тохируулаагүй хэлбэрүүд checkout дээр автоматаар нуугдана. Нэр, тайлбар, дараалал нь `js/data.js` → `PAYMENT_METHODS`-д байна.

### Холболт хийх алхам

1. **QPay** — [developer.qpay.mn](https://developer.qpay.mn); merchant гэрээ, sandbox түлхүүрийг support@qpay.mn-ээс авна. Эхлээд `QPAY_BASE_URL=https://merchant-sandbox.qpay.mn`-ээр туршаад дараа нь `https://merchant.qpay.mn` болгоно.
2. **Голомт банк** — [dev.golomtbank.com](https://dev.golomtbank.com:7443/docs/ecommerce_api_invoice_en); eMerchant-аар бүртгүүлж, merchant@golomtbank.com-оос токен ба HMAC түлхүүр авна. Checksum-ийн томьёо, туршилтын орчныг банктай заавал нягтална уу.
3. **Storepay** — нийтэд нээлттэй API олдоогүй тул гар горимоор ажиллана.
4. **MonPay, Toki, HiPay** — нийтэд нээлттэй API баримт олдоогүй. Хэрэгтэй бол merchant API-гаа авч `server/payments/` дотор ижил бүтэцтэй модуль нэмнэ.
5. **Telegram мэдэгдэл** — @BotFather-аас бот үүсгэж токеныг `TELEGRAM_BOT_TOKEN`-д; ботдоо мессеж бичээд `https://api.telegram.org/bot<TOKEN>/getUpdates`-ээс chat id-гаа олж `TELEGRAM_CHAT_ID`-д оруулна.

## Захиалгын төлөв

`Хүлээгдэж буй` → `Төлөгдсөн` → `Хүргэлтэнд гарсан` → `Хүлээлгэн өгсөн`, эсвэл `Цуцлагдсан`.

- QPay, карт, SocialPay-ээр төлсөн захиалга автоматаар «Төлөгдсөн» болно. Бусдыг админ гараар солино.
- Захиалга өгөхөд үлдэгдэл хасагдана. Цуцлахад үлдэгдэл ба промо кодын хэрэглээ буцна. Төлөгдөөгүй хоцорсон захиалгыг цуцалж үлдэгдлээ чөлөөлөөрэй.
- Үйлчлүүлэгч «Захиалга хянах» хэсгээс дугаар + утсаараа төлвөө харна.

## Аюулгүй байдал

- Үнэ, хөнгөлөлт, хүргэлт, үлдэгдлийг үйлчлүүлэгчийн хөтчөөс биш, сервер дахин тооцдог.
- QPay, Голомт, Telegram-ын нууц түлхүүр, админ нууц үг зөвхөн `.env` дотор (сервер талд) байна.
- Төлбөрийн төлвийг үргэлж банкнаас (`/v2/payment/check`, Голомтын `inquiry`) шалгаж баталгаажуулна. QPay давтан poll хийхийг хориглодог тул зөвхөн callback ирэх эсвэл «Төлбөр шалгах» дарах үед шалгана.
- Админ: HttpOnly + SameSite=Strict cookie, 12 цагийн session, 5 удаа буруу оролдвол 15 минут түгжинэ. Өөрчлөх хүсэлт зөвхөн JSON. Сервер дахин асахад нэвтрэлт дуусна.
- Зураг: зөвхөн JPG/PNG/WEBP, 4MB хүртэл, файлын эхний байтаар төрлийг шалгана.
