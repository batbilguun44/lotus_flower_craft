# Lotus Flower Craft — онлайн дэлгүүр

Гэрийн ургамал, шүүслэг/кактус, зохиомж, улирлын ургамал болон баглаа цэцгийн статик e-commerce сайт. Build хийх шаардлагагүй — HTML, CSS, JavaScript.

## Ажиллуулах

```bash
python3 -m http.server 8000
# http://localhost:8000
```

GitHub Pages, Netlify, Vercel зэрэгт шууд байрлуулж болно.

## Бүтэц

| Файл | Агуулга |
| --- | --- |
| `index.html` | Хуудасны бүтэц |
| `css/styles.css` | Загвар |
| `js/data.js` | **Дэлгүүрийн мэдээлэл, ангилал, бүтээгдэхүүн** — ихэнх өөрчлөлтийг эндээс хийнэ |
| `js/app.js` | Шүүлтүүр, хайлт, сагс, захиалгын логик |
| `assets/Lotus_flow_craft_logo_new.svg` | Лого |

## Солих шаардлагатай зүйлс

1. **Лого** — `assets/Lotus_flow_craft_logo_new.svg` нь түр зуурын лого. Жинхэнэ `Lotus_flow_craft_logo_new.svg` файлаа яг ижил нэрээр нь энд хуулна.
2. **Үнэ, холбоо барих мэдээлэл** — `js/data.js` дахь `SHOP` (утас, и-мэйл, хаяг, сошиал холбоос, хүргэлтийн төлбөр) болон бүтээгдэхүүний `price` нь түр утга.
3. **Зураг** — бүтээгдэхүүнд бодит зураг нэмэхдээ `assets/img/` дотор хийгээд `image: "assets/img/zz-plant.jpg"` гэж заана. Зураггүй бол ургамлын дүрслэл автоматаар харагдана.

Бүтээгдэхүүн нэмэх жишээ (`js/data.js` → `PRODUCTS`):

```js
{
  id: "monstera",
  name: "Монстера",
  category: "houseplants",   // houseplants | succulents | arrangements | seasonal | bouquets
  price: 55000,              // null бол "Үнэ тохиролцоно" + "Асуух" товч
  care: "Хялбар", light: "Сарнисан гэрэл", water: "Долоо хоногт нэг",
  badge: "Шинэ",
  desc: "Тайлбар…",
  image: "assets/img/monstera.jpg",
  colors: ["#2f5d3a", "#4f8a5b"], // зураггүй үеийн дүрслэлийн өнгө
}
```

## Захиалгын урсгал

Сагс болон захиалга нь хэрэглэгчийн хөтчийн `localStorage`-д хадгалагдана. Сервер байхгүй тул захиалга дэлгүүр рүү автоматаар **илгээгдэхгүй** — баталгаажуулалтын цонхонд захиалгын товч мэдээлэл гарч, хэрэглэгч хуулж авах боломжтой. Бодит захиалга хүлээн авахын тулд `js/app.js` доторх `submitOrder` функцээс Google Forms, Formspree, Telegram bot эсвэл өөрийн API руу илгээх хэрэгтэй. QPay төлбөрийг мөн сервер талд холбох шаардлагатай.
