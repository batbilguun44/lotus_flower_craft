# Lotus Flower Craft — онлайн дэлгүүр

Гэрийн ургамал, шүүслэг/кактус, зохиомж, улирлын ургамал болон баглаа цэцгийн e-commerce сайт. Build хийх шаардлагагүй — HTML, CSS, JavaScript, төлбөрийн хэсэгт жижиг Node.js сервер.

## Ажиллуулах

Хоёр горимтой:

```bash
# 1) Сервертэй — QPay, карт, SocialPay ажиллана (Node 18+, нэмэлт сан хэрэггүй)
cp .env.example .env   # түлхүүрүүдээ оруулна
npm start              # http://localhost:8000

# 2) Статик — GitHub Pages, Netlify гэх мэт. Зөвхөн гараар баталгаажуулах төлбөр.
python3 -m http.server 8000
```

## Солих шаардлагатай зүйлс

1. **Лого** — `assets/Lotus_flow_craft_logo_new.svg` нь түр зуурын лого. Жинхэнэ `Lotus_flow_craft_logo_new.svg` файлаа яг ижил нэрээр нь энд хуулна.
2. **Үнэ, холбоо барих мэдээлэл** — `js/data.js` дахь `SHOP` (утас, и-мэйл, хаяг, сошиал холбоос, хүргэлтийн төлбөр) болон бүтээгдэхүүний `price` нь түр утга.
3. **Зураг** — бүтээгдэхүүнд бодит зураг нэмэхдээ `assets/img/` дотор хийгээд `image: "assets/img/zz-plant.jpg"` гэж заана. Зураггүй бол ургамлын дүрслэл автоматаар харагдана.

Бүтээгдэхүүн нэмэх жишээ (`js/data.js` → `PRODUCTS`):

```js
{
  id: "monstera",
  name: "Монстера",
  category: "houseplants",   // houseplants | succulents | arrangements | seasonal | bouquets
  price: 55000,              // null бол "Үнэ тохиролцоно" + "Асуух" товч
  care: "Хялбар", light: "Сарнисан гэрэл", water: "Долоо хоногт нэг",
  badge: "Шинэ",
  desc: "Тайлбар…",
  image: "assets/img/monstera.jpg",
  colors: ["#2f5d3a", "#4f8a5b"], // зураггүй үеийн дүрслэлийн өнгө
}
```

## Төлбөрийн хэлбэрүүд

| Хэлбэр | Хэрхэн ажиллах | Шаардлага |
| --- | --- | --- |
| **QPay** | QR нэхэмжлэх үүсгэж, бүх банкны апп-аар уншуулна. Утсан дээр банкны апп руу шууд холбоос гарна. Төлсний дараа QPay callback ирж захиалга "төлөгдсөн" болно. | QPay-тэй merchant гэрээ → `QPAY_*` |
| **QPay (сервергүй)** | Дэлгүүрийн тогтмол QR зургийг харуулж, гүйлгээний утга дээр захиалгын дугаар бичүүлнэ. Гараар баталгаажуулна. | `SHOP.qpayStaticQr` |
| **SocialPay** | Голомт банкны gateway → SocialPay апп руу шилжинэ. | Голомттой e-commerce гэрээ → `GOLOMT_*` |
| **Карт** (Visa, Mastercard, UnionPay) | Голомт банкны картын хуудас руу шилжиж, буцаж ирэхэд банкнаас төлөвийг шалгана. | Голомттой e-commerce гэрээ → `GOLOMT_*` |
| **Дансаар шилжүүлэх** | `SHOP.bankAccounts` дахь данс, гүйлгээний утгыг хуулах товчтой харуулна. | — |
| **Storepay** (хуваан төлөх) | 100,000₮-с дээш захиалгад. Дэлгүүр Storepay-ээр дамжуулан үйлчлүүлэгчийн утас руу нэхэмжлэх илгээнэ (merchant гэрээний дагуу). | Storepay-тэй merchant гэрээ |
| **Хүргэлтээр төлөх** | Бэлнээр эсвэл картаар. | — |

Түлхүүр тохируулаагүй хэлбэрүүд checkout дээр автоматаар нуугдана. Хэлбэрүүдийн нэр, тайлбар, дараалал `js/data.js` → `PAYMENT_METHODS`-д байна.

### Аюулгүй байдал

- Үнийг үйлчлүүлэгчийн хөтчөөс биш, сервер `js/data.js`-ээс дахин тооцдог.
- QPay, Голомтын нууц түлхүүр зөвхөн `.env` дотор (сервер талд) байна.
- Төлбөрийн төлвийг үргэлж банкнаас (`/v2/payment/check`, Голомтын `inquiry`) шалгаж баталгаажуулна. QPay давтан poll хийхийг хориглодог тул зөвхөн callback ирэх эсвэл үйлчлүүлэгч "Төлбөр шалгах" дарах үед шалгана.
- QPay callback болон Голомтын буцах хаяг ажиллахын тулд `PUBLIC_URL` нь интернэтээс хандах боломжтой **https** хаяг байх ёстой.

### Холболт хийх алхам

1. **QPay** — [developer.qpay.mn](https://developer.qpay.mn) баримт бичиг; merchant гэрээ, sandbox түлхүүрийг support@qpay.mn-ээс авна. Эхлээд `QPAY_BASE_URL=https://merchant-sandbox.qpay.mn`-ээр туршаад дараа нь `https://merchant.qpay.mn` болгоно.
2. **Голомт банк** — [dev.golomtbank.com](https://dev.golomtbank.com:7443/docs/ecommerce_api_invoice_en) баримт бичиг; eMerchant-аар бүртгүүлж, merchant@golomtbank.com-оос токен ба HMAC түлхүүр авна. Checksum-ийн томьёо, туршилтын орчныг банктай заавал нягтална уу.
3. **Storepay** — нийтэд нээлттэй API олдоогүй тул одоогоор гар горимоор ажиллана. Merchant гэрээ байгуулахдаа API холболтын боломжийг асуугаарай.
4. **MonPay, Toki, HiPay** — нийтэд нээлттэй API баримт олдоогүй (HiPay-г Antom-оор дамжуулан холбох боломжтой). Хэрэгцээтэй бол тухайн компаниас merchant API-гаа авч, `server/payments/` дотор ижил бүтэцтэй модуль нэмнэ.

## Захиалгын урсгал

- **Сервертэй горим:** захиалга `data/orders.json`-д хадгалагдана (дугаар, үйлчлүүлэгч, бараа, төлбөрийн төлөв `pending` → `paid`).
- **Статик горим:** сервер байхгүй тул захиалга зөвхөн үйлчлүүлэгчийн хөтчид хадгалагдана. Баталгаажуулалтын цонхонд захиалгын мэдээллийг хуулах товч гарна.
